# IoT Sensor Data Collection System

## Обзор проекта

Система сбора данных с датчиков на базе Arduino Mega 2560 с использованием FreeRTOS для многозадачности. Проект реализует периодический сбор данных с аналогового датчика и формирование структурированных отчетов о состоянии системы.

## Архитектура системы

### Задачи FreeRTOS

1. **Task 1 (task1_button_led)** - Управление кнопкой и светодиодом
   - Период: 10 мс (vTaskDelayUntil)
   - Функции: обработка нажатий кнопки, управление зеленым LED, подача семафора

2. **Task 2 (task2_provider)** - Синхронная задача
   - Ожидает семафор от Task 1
   - Отправляет последовательность байтов 1..N с интервалом 50 мс
   - Мигает синим LED N раз (ON: 300мс, OFF: 500мс)

3. **Task 3 (task3_consumer)** - Асинхронная задача
   - Период: 200 мс
   - Считывает очередь байтов и выводит в терминал
   - При байте 0 переходит на новую строку

4. **Task 4 (task4_sensor_reader)** - Сбор данных с датчика
   - Период: 250 мс (vTaskDelayUntil)
   - Считывает аналоговый датчик (A0)
   - Обрабатывает сигналы и проверяет валидность
   - Отправляет данные в очередь для отображения

5. **Task 5 (task5_system_monitor)** - Мониторинг системы
   - Период: 500 мс (vTaskDelayUntil)
   - Формирует структурированные отчеты о состоянии
   - Выводит данные через STDIO (Serial/LCD)

### Модули системы

#### Sensor Module (`lib/sensor_module/`)
- **sensor_module.h** - API для работы с датчиками
- **sensor_module.cpp** - Реализация модуля датчика
- Поддерживает аналоговые датчики (потенциометр, фоторезистор)
- Обработка ошибок и валидация данных
- Конвертация Raw ADC → Voltage → Percentage

#### Existing Modules
- **own_stdio** - Абстракция STDIO для Serial/LCD вывода
- **led_control** - Управление светодиодами
- **button_control** - Обработка кнопок с дебаунсом
- **tasks** - Координация FreeRTOS задач

## Конфигурация оборудования

### NTC Температурный датчик (Wokwi)
- **Пин**: A0 (аналоговый вход)
- **Тип**: NTC термистор (Negative Temperature Coefficient)
- **Диапазон**: -40°C до +125°C
- **Точность**: ±2°C (типичная для NTC термистора)
- **Период считывания**: 250 мс
- **Характеристики**: Beta = 3950, R25 = 10kΩ при 25°C
- **Особенности**: Wokwi NTC со встроенным pull-up резистором

### Светодиоды
- **Зеленый LED**: Pin 12 (Task 1 - индикация нажатия кнопки)
- **Синий LED**: Pin 10 (Task 2 - мигание N раз)

### Кнопки
- **Основная кнопка**: Pin 6 (ON/OFF функция)
- **Дополнительные**: Pin 3, Pin 1

### Связь
- **Serial**: 115200 бaud для отчетов и отладки
- **LCD**: I2C адрес 0x27 (опционально)

## Протокол отчетов

### Системный отчет (каждые 500 мс)
```
==== SYSTEM STATUS REPORT ====
Uptime: 1234 seconds
Button presses (N): 5
Total sensor reads: 2468
Sensor errors: 0
Latest sensor: NTC Temperature Sensor: 25.3°C (39.6%) [RAW:512] [OK] [ERR:0] [TIME:123456]
DEBUG: RAW=512, V=2500mV
Temperature: 25.3°C (39.6%)
===============================
```

### Формат данных NTC температурного датчика
- **Temperature**: Температура в градусах Цельсия (-40.0 до +125.0°C)
- **Percentage**: Нормализованное значение (0.0-100.0% от диапазона)
- **Raw**: Сырое значение ADC (0-1023)
- **Status**: OK/ERROR/OUT_OF_RANGE/NOT_CONNECTED
- **Error Count**: Количество последовательных ошибок
- **Timestamp**: Время считывания в миллисекундах

### Преобразование сигнала NTC
1. **ADC → Voltage**: Raw значение (0-1023) → напряжение (0-5V)
2. **Voltage → NTC Resistance**: Расчет сопротивления NTC через делитель напряжения
   - `R_ntc = R_pullup × Vout / (Vin - Vout)`
3. **Resistance → Temperature**: Упрощенная формула Стейнхарта-Харта для NTC
   - `1/T = 1/T0 + (1/Beta) × ln(R_ntc/R25)`
4. **Temperature → Percentage**: Нормализация в диапазоне -40°C...+125°C

### Особенности NTC датчика
- **NTC**: Сопротивление уменьшается с ростом температуры
- **Beta коэффициент**: 3950K (характеристика материала NTC)
- **R25**: 10kΩ - сопротивление при 25°C
- **Встроенный pull-up**: Wokwi NTC имеет внутренний резистор

## Требования к проекту - выполнение

- **Съем сигналов**: Аналоговый датчик через analogRead() с конвертацией

- Thread-safe обмен данными через FreeRTOS очереди
- Обработка ошибок с счетчиками и статусами
- Детальная отчетность с временными метками

## Сборка и запуск

### Требования
- PlatformIO
- Arduino Mega 2560 или симулятор Wokwi

### Команды сборки
```bash
# Сборка проекта
platformio run -e megaatmega2560

# Загрузка на плату
platformio run -e megaatmega2560 -t upload

# Мониторинг Serial
platformio device monitor -b 115200
```

### Симуляция в Wokwi
1. Откройте `diagram.json` в Wokwi
2. Загрузите файл `firmware.hex`
3. Кликните на NTC датчик и установите температуру (например: -10°C, 0°C, 25°C, 50°C, 100°C)
4. Наблюдайте изменения температурных показаний в Serial Monitor
5. Проверьте корректность преобразования и отображения температуры
6. Тестируйте пороговые значения и обработку ошибок

## Диагностика

### Индикация работы
- **Зеленый LED**: Мигает при нажатии кнопки (1 сек)
- **Синий LED**: Мигает N раз после нажатия кнопки
- **Serial**: Отчеты каждые 500 мс + данные из Task 3

### Проблемы и решения
- **Датчик не отвечает**: Проверьте подключение к A0 и питание датчика
- **Нет отчетов**: Проверьте Serial соединение (115200 baud)
- **Неверные температуры**: Проверьте параметры NTC (Beta=3950, R25=10kΩ)
- **Ошибки OUT_OF_RANGE**: Температура вне диапазона -40°C...+125°C
- **Нестабильные показания**: Добавьте сглаживающий конденсатор или программную фильтрацию
